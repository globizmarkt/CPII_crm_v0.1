## 2. DOCTRINAS TÉCNICAS

### Globales (afectan a Bulldozer directamente)
- **R3 — Zero-Hex:** Prohibido usar valores hexadecimales de color directamente en HTML/CSS. Usar exclusivamente las variables Tailwind definidas en `tailwind.config` (`primary`, `background-dark`, `card-dark`, `border-dark`, `text-secondary`)
- **R4 — i18n obligatorio:** Todo texto visible al usuario debe tener su `data-i18n` correspondiente en los 4 idiomas (PT/ES/EN/FR). Texto hardcodeado en HTML es violación de R4
- **Vanilla JS + Tailwind:** Zero dependencias externas no aprobadas. Sin frameworks, sin jQuery, sin Alpine
- **Zero-Server:** Sin backend propio — Firebase Hosting + Cloud Functions exclusivamente

### Doctrinas específicas emergidas en el trabajo real
- **Doctrina de ancla única:** Antes de insertar claves en i18n.js, verificar que el texto ancla es único en todo el archivo. Si PT y ES tienen el mismo string ancla, Python replace() tocará solo el primero — usar strings diferenciados o posición por línea
- **Doctrina de fuente de verdad:** La versión desplegada en Firebase es siempre la fuente de verdad. La versión en sesión de Bulldozer puede estar N sprints por detrás
- **Doctrina del tab oculto:** Los tabs con `class="hidden"` son procesados por el motor i18n en carga — el bug de traducción no era de visibilidad sino de claves duplicadas con orden incorrecto
- **Doctrina stealth_referral:** Los embajadores no públicos se inyectan como `<option>` via JS en runtime. El `<select>` HTML solo expone a David Almeida y Carlos Balboa. El array `EMBAJADORES_AUTORIZADOS` es la lista maestra real
- **Doctrina localStorage vs sessionStorage:** El sistema usa `localStorage` para persistencia cross-navegación del ref de embajador (mejora respecto a la versión inicial con `sessionStorage`)

## 4. DECISIONES DESCARTADAS Y POR QUÉ

| Decisión | Motivo del descarte |
|----------|---------------------|
| Un archivo HTML por embajador | Infierno de mantenimiento — cualquier cambio de copy requeriría N deploys |
| `sessionStorage` para persistencia de ref | No sobrevive a navegación cross-tab ni a cierre/apertura del navegador — reemplazado por `localStorage` |
| Countdown con target 2026-02-27 | Fecha expirada — generaba "🔴 AO VIVO" permanente. Actualizado a 2026-03-28 |
| Léxico "Masterclasses" / "Breeder Hub" | Léxico low-ticket incompatible con posicionamiento institucional — reemplazado por "Comités de Inversión" / "Deal Flow Sessions" |
| Léxico "Prescriptor" / "Padrino" | Purificado en producción — reemplazado por "Embajador" |
| Inserción de claves i18n con `str.replace()` sin ancla única | Primer pase del hotfix de webinars tabs: todas las inserciones cayeron en bloque PT porque PT y ES tenían el mismo string ancla. Resuelto usando el valor traducido de `webinars.cal.title` como ancla diferenciadora |
| Claves antiguas webinars.cal.e* mantenidas junto a las nuevas | Bug silencioso: JS usa la última definición — las antiguas (FEV/FEB) sobreescribían las nuevas (MAR/ABR). Resuelto eliminando el bloque antiguo |
| `parse_mode: "Markdown"` en Cloud Function Telegram | Error 400 Bad Request con caracteres especiales (guiones bajos, +) en nombres de usuarios. Resuelto con `parse_mode: "HTML"` |
| Grid `lg:grid-cols-12` en simulator | Columna derecha se descolgaba en 768-1024px — breakpoint cambiado a `md:grid-cols-12` |
| Grid closure mal posicionado en referrals | El `</div>` de cierre del grid estaba dentro de `col-span-8` — columna derecha quedaba huérfana. Reposicionado después de ambas columnas |

## 6. CONOCIMIENTO TÁCITO DEL PROYECTO

### Estructura de poder
- **Director:** Toma decisiones estratégicas, aprueba arquitectura, ejecuta deploys directamente cuando el archivo es grande
- **Lead Architect (Gemini):** Emite el diseño técnico de nivel 2. Sus instrucciones son condición necesaria para intervenciones multi-archivo. Bulldozer implementa lo que Gemini diseña
- **Bulldozer (Claude):** Ejecuta las incisiones, detecta bugs, mantiene i18n, emite diagnósticos

### Sensibilidades de negocio
- El léxico es estratégico — "Masterclasses" → "Comités", "Prescriptor" → "Embajador", "Breeder Hub" → "CPII Portugal". Cada cambio de palabra es una decisión de posicionamiento, no cosmética
- La lista de embajadores es información sensible — no debe exponerse en el HTML público por razones competitivas y de privacidad de los agentes
- David Almeida y Carlos Balboa son los dos "closers" públicos — todo tráfico orgánico sin referido se atribuye a ellos
- El sistema KYC/AML no es decorativo — es el diferenciador legal y comercial del grupo
- Firebase proyecto `cpii-landing` ≠ `clubsocios-prod` — siempre verificar que se opera en el proyecto correcto antes de deploy

### Patrones que funcionan
- Tailwind dark/gold: `bg-primary` (#C1A85D), `bg-background-dark` (#161513), `bg-card-dark` (#1e1b14) — esta paleta es inviolable
- Grid `md:grid-cols-12` con `items-start` y `min-w-0` en columna derecha — patrón estable para layouts de 2 columnas
- `overflow-x-auto` + `.hide-scrollbar` + `min-w-[900px]` para árboles de red en mobile
- Python para manipulaciones masivas de i18n.js — bash sed falla con caracteres especiales multiidioma
- Anclas únicas por idioma usando el valor traducido del string como diferenciador

### Trampas conocidas
- **La trampa del ancla compartida:** PT y ES pueden tener strings idénticos en i18n.js. Siempre usar el valor traducido (diferente por idioma) como ancla, nunca la clave
- **La trampa del tab oculto:** Los tabs `hidden` sí reciben traducciones — el bug de i18n en tabs NO es de visibilidad
- **La trampa del objeto JS con claves duplicadas:** Insertar claves nuevas antes de las antiguas = las antiguas ganan. Siempre eliminar las antiguas o insertar las nuevas al final del bloque
- **La trampa del tamaño de archivo:** i18n.js > límite de contexto. Sin el archivo subido, cualquier operación sobre él es ciega
- **La trampa del entorno:** El Director tiene dos proyectos Firebase. Verificar `.firebaserc` antes de cualquier deploy
