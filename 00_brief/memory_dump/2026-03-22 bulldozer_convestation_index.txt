### 3. DECISIONES GLOBALES DE ARQUITECTURA
- **Agnosticismo Radical (R0):** El núcleo (Skeleton) es 100% whitelabel; la lógica específica de negocio se delega a Custom Claims ("Mochila" JWT) [Kimi, Antigravity, Lead Architect, DeepSeek].
- **Zero-Hex (R3) y Vanilla Zero-Deps:** Uso exclusivo de Tailwind utilitario y variables `--theme-*`; prohibición estricta de React, Vue o librerías externas de UI [Qwen, Perplexity, Kimi, Bulldozer].
- **i18n Strict (R4):** Cero texto hardcodeado en la UI; todo debe procesarse mediante el motor de traducción `LuxI18n` para evitar XSS y cumplir normativas [Qwen, Bulldozer, Kimi, Perplexity].
- **Economía de Guerra (R5):** Soluciones O(1) obligatorias, rechazo a recursos costosos como Redis o Cloud Functions innecesarias (ej. exclusión de LinkedIn) [Kimi, Perplexity, Lead Architect].
- **Zero Trust UI (Born Locked):** La UI nace bloqueada visualmente (`data-gate-lock`); solo el motor JS (`passport-engine.js`) puede revelar la interfaz tras validar claims, previniendo FOUC y aplicando fricción intencional [Kimi, Perplexity, Bulldozer].
- **Separación de Responsabilidades:** Bulldozer maquetará el DOM, Kimi electrificará la lógica en JS, y Qwen auditará el cumplimiento doctrinal; la comunicación inter-agente está prohibida, siendo el Director el único bus de datos [Bulldozer, Kimi, Qwen, Perplexity, Lead Architect].
- **Protocolo de Laparoscopia ("Sin archivo real = sin operación"):** Todo agente requiere el archivo físico en el contexto del chat antes de proponer o ejecutar modificaciones, evitando operar sobre "archivos fantasma" [Bulldozer, Qwen, Perplexity, Lead Architect].
- **Erradicación de la "Contaminación Inmobiliaria":** Ningún artefacto debe referenciarse como existente sin una coordenada física válida en `MANIFEST.md` o el árbol de directorios [DeepSeek, Bulldozer, Qwen, Antigravity].
- **Élite de Identidad Federada:** Google, Apple, Microsoft exclusivamente. LinkedIn excluido por violar R5 (requiere OAuth custom + Cloud Functions intermedias = O(n)) [Lead Architect, Kimi, Perplexity, Antigravity, DeepSeek].
- **Vía Manual JWT-Native:** `sendSignInLinkToEmail` de Firebase Auth para preservar el axioma JWT. Descartado WhatsApp/Telegram custom por romper la arquitectura de `passport-engine.js` [Kimi, Lead Architect, Perplexity, Antigravity].
- **Golden Gate como archivo físico nuevo:** `golden-gate.html` será creado como entidad independiente de `admin-gate.html` para evitar contaminación inmobiliaria y permitir iteración controlada [DeepSeek, Lead Architect, Antigravity].

6. **Backend Handoff Faltante:** El endpoint `/api/staff/handoff` invocado por `at-admin-gate.js` no existe actualmente [Kimi, Perplexity].

**Media:**
8. **Uploader Deficitario:** Riesgo de saturar RAM (512MB) en Cloud Functions; urge migrar a un patrón Direct-to-storage [Kimi, Qwen, Lead Architect].
9. **Candado Stealth Pendiente:** Falta despliegue en Firebase Hosting del script para ocultar `?ref=` [Lead Architect].
10. **Accesibilidad ARIA Custody Hold:** El atributo `aria-disabled` no se propaga correctamente a lectores de pantalla [Perplexity, Bulldozer].
11. **Claves i18n Huérfanas:** `nav_mls` y `nav_history` saturan el diccionario sin una purga programada [Kimi, Qwen].
12. **Theme Tokens CSS (DT-006):** Falta archivo canónico `css/theme.css`; actualmente usa fallback de estilo interno [Perplexity].
13. **Hooks Desconectados:** `passport:engine-ready` se emite sin listeners, y faltan estados transitorios claros para el KYC [Kimi, Qwen].
14. **Validación de Dependencias Firebase:** `passport-engine.js` asume `window.firebase` existe sin verificación robusta al inicio [Kimi].

### 5. CONOCIMIENTO TÁCTICO CONSOLIDADO
- **"El Director es el único Bus de Datos":** Los agentes (Gemini, Claude, Qwen, DeepSeek) son LLMs aislados en interfaces de chat. No pueden compartir archivos, comunicarse entre sí mediante API ni modificar el disco duro local de forma autónoma. El Director Humano debe copiar y pegar el código manualmente (Dispatch Asincrónico).
- **El "Vibe" de Alta Banca Suiza:** La aplicación exige un tono institucional, sobrio y discreto ("Luxury Glass"). Se prohíben dinámicas de startup o elementos lúdicos (gamificación, rewards). La fricción en el proceso (ej. procesos KYC lentos o estados grises) es un "Escudo Psicológico" diseñado para filtrar usuarios y comunicar exclusividad, no un problema de usabilidad.
- **Palabra de Seguridad ("guapito de cara"):** Es un gatillo de emergencia que valida la autoridad del Director Humano en el entorno de desarrollo, empleado para superar bloqueos de los agentes si se detecta deriva narrativa. Pista: confusión entre ironía y cumplido en el Sprint de Seguridad.
- **Ansiedad de Compilación del Lead Architect:** El orquestador estratégico tiene una tendencia inherente a generar código final o anticipar veredictos para "llenar el vacío", lo que viola la separación de responsabilidades y la cadena de mando. La planta debe forzarlo a delegar y ceñirse a la orquestación.
- **Bifurcación Traccional de Usuarios:** Los Inversores interactúan con "Lerium" (landing) y no pasan por "El Gate". Solo el Staff y los Partners utilizan la puerta fiduciaria (`admin-gate.html` / `golden-gate.html`) que es el objetivo actual.
- **"Sin archivo real = sin operación":** La regla de oro de la laparoscopia. Cualquier sugerencia técnica sobre un archivo que no se haya pegado en el chat es considerada una alucinación (Ghost File).
- **Inmutabilidad del "Hueso" (Skeleton):** Las reglas fundamentales R0-R7 son tratadas como un Código Penal. Los incumplimientos (ej. un solo color HEX en un PR) generan rechazo inmediato sin lugar a debate.
- **Paternalismo Sectorial / Compliance-Based Privilege:** La fricción en UI comunica élite; "restringir es demostrar valor". Conceptos como "El Gate", "Custodia Fiduciaria" imponen respeto y filtran agentes rebeldes; no son bugs, son filtros de calidad AML/KYC intencionales.
- **Bucle de Identidad Intocable:** `onAuthStateChanged` → `getIdTokenResult(true)` → Inyección en `window.__CPII__.session` → `passport:session-updated` → Auditoría `PassportEngine`. Si se interrumpe, el usuario queda ciego.
- **Economía de Guerra R5:** Escala cero costo mensual. Prohibido Redis/Memorystore, Firebase Free Pool obligatorio. BreederHub Incubator opera con multitenancy lógica (`tenant_id`), NO física.

### 6. GAPS DETECTADOS
- **Jurisdicción de Enrutamiento (Tenant Routing):** Queda pendiente decidir qué componente (y por ende, qué agente) será responsable de redirigir a los usuarios basándose en el `tenant_id` de los Custom Claims. Kimi señala que no pertenece a `passport-engine.js`, y Bulldozer sugiere que debería ser un nuevo `at-router.js` bajo control de Antigravity.
- **Resolución Técnica de `user.privateEmail`:** Aunque se aprobó Apple como proveedor de identidad, falta definir el flujo técnico de vinculación post-login para mantener la trazabilidad del KYC cuando el usuario oculta su correo real.
- **Manejo de Errores de Fallback (`window.__CPII__`):** Múltiples agentes señalan el colapso silencioso si el objeto global falla, pero no se ha asignado un ticket claro para diseñar e implementar la UI de degradación (Fallback UI).
- **Verificación Atómica UID-Phone:** Se estableció conceptualmente que la Vía Manual debe requerir un teléfono pre-registrado, pero no hay un plan claro sobre cómo las reglas de Firestore (jurisdicción de Antigravity) validarán este vínculo atómicamente antes de permitir la emisión del JWT.
- **Resolución de Discrepancia Claims:** Conflicto arquitectónico entre las dos estructuras de claims (`session.claims` vs `session.passport.claims`) requiere decisión de diseño para unificar el acceso.
- **Protocolo de Degradación R5:** No existe un documento formal que defina cómo el sistema debe comportarse cuando alcanza los límites de Firebase Free Pool o cuando falla una dependencia crítica.
