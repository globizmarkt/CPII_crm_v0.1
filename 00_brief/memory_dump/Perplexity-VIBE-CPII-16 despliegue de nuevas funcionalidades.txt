## DOCTRINAS TÉCNICAS

**Globales (del System Prompt):**
- **R3 (Zero-Hex):** Prohibido colores hexadecimales. Solo Tailwind classes/tokens CSS
- **R4 (i18n):** Nunca textos hardcodeados. Solo `data-i18n-key` + motor externo
- **Arquitectura Trinity:** DOM nativo + Vanilla JS + CustomEvents/MutationObserver
- **Ecosistema Cerrado:** Nada fuera de index.html existe

**Específicas Frontend/UX (emergidas):**
- **Doctrina Custody Hold:** Estados locked = `opacity-60 pointer-events-none border-warning/50 + badge HOLD`
- **Microcopy Fiduciario:** Checklist ▶ + ETA + "Habilitación Pendiente" (no "bloqueado")
- **Jerarquía Visual:** Fase1=verde libre, Fase2=warning HOLD, Fase3=amber VIP
- **Tooltip Pattern:** 240px min, backdrop-blur, checklist actionable (3s lectura máx)
