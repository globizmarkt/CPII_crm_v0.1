### 3. DECISIONES GLOBALES DE ARQUITECTURA
- **Agnosticismo Radical (R0):** El núcleo (Skeleton) es 100% *whitelabel*. La lógica de negocio se inyecta vía Custom Claims ("Mochila" JWT).
- **Light DOM (R2):** Prohibido el uso de Shadow DOM para garantizar la permeabilidad visual y la herencia de tokens CSS.
- **Tailwind Zero-Hex (R3):** Inmutabilidad cromática. Prohibidos los colores hexadecimales; uso exclusivo de variables `--theme-*`.
- **i18n Strict (R4):** Cero texto hardcodeado. Todo contenido visible debe estar registrado en el diccionario para prevenir XSS y permitir multijurisdicción.
- **Economía de Guerra (R5):** Máxima eficiencia O(1). Exclusión de proveedores de identidad no nativos (LinkedIn) para evitar latencia y costes de infraestructura innecesarios.
- **Zero Trust UI (Born Locked):** Los componentes de acceso nacen bloqueados (`data-gate-lock`). Solo el motor de pasaporte puede liberar la interfaz tras validación fiduciaria.
